# 优先走官方通道，官方通道缺位处才用 DOM 补丁

DSH 的插件扩展点分两类：**官方通道**（`ctx.slots` 插槽、`ctx.shortcuts`、`InputTriggerSource`、bundle patch）与 **DOM 补丁**（直接读写宿主渲染出的 DOM）。官方通道不依赖构建哈希与 DOM 结构，随上游升级更稳；DOM 补丁见效快但绑死内部实现。

我们优先官方通道。仅当上游没有暴露对应扩展点时（例如 Lexical 编辑器内部的引用高亮判定、跨 tab 单一实例的面板），才用 DOM 补丁，且只依赖**稳定锚点**（`data-*` 属性、`class*="_后缀"`），并在插件内注释说明该补丁的兜底性质与上游开放通道后的替换方向。

理由：这个包按可发布标准设计（ADR-0001），而 DOM 补丁是它最容易腐坏的部分。把"何时允许 DOM 补丁"写成规矩，可以避免后来者为了方便而扩大补丁面积。
